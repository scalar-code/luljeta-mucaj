# Luljeta Rama Muçaj

Website for Luljeta Rama Muçaj, visual artist, graphic designer and art teacher from Prishtina.

A single static page (`index.html`) with five sections: Home, About, Work, Teaching and Contact. No build step: open `index.html` in a browser, or serve the folder with any static host such as GitHub Pages.

- `index.html`: the whole site (HTML, CSS and JavaScript)
- `img/`: photos of her, her exhibitions and her paintings (`art-01.jpg` to `art-12.jpg`)

website is https://scalar-code.github.io/luljeta-mucaj/
